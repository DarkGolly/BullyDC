# Правила для Claude Code в этом проекте

- Никогда не добавляй себя (Claude/AI) в соавторы коммитов. Не добавляй строки вида
  `Co-Authored-By: Claude ...` и любые другие упоминания ассистента в сообщениях коммитов.
- В начале новой сессии проверяй память проекта на незавершённые фичи/задачи из прошлых
  диалогов (см. project-памяти). Если находишь такие — сообщи о них пользователю и предложи
  вернуться к ним, прежде чем переходить к новому запросу.
